# Обновления HolyPresenter

Начиная с версии 1.0.8 пользователь может обновить установленную программу из
встроенного модуля **«Обновления»**. Удалять старую версию и повторно настраивать
HolyPresenter не нужно.

## Как это работает

1. HolyPresenter запрашивает последний опубликованный Release репозитория
   `maxx52/HolyPresenter` через GitHub REST API.
2. Программа выбирает MSI-файл и требует SHA-256, который GitHub вычисляет для
   загруженного asset. Без контрольной суммы установка блокируется.
3. MSI скачивается в `%LOCALAPPDATA%\HolyPresenter\updates`, проверяется по
   размеру и SHA-256.
4. После подтверждения HolyPresenter корректно закрывает сервисы, запускает
   скрытый помощник обновления и освобождает файлы программы.
5. Windows показывает стандартный запрос UAC, устанавливает MSI поверх текущей
   версии и снова открывает HolyPresenter.

Настройки, планы, резервные копии, песни и установленные пользователем модули
находятся в `%LOCALAPPDATA%\HolyPresenter`, поэтому MSI их не удаляет.

## Публикация обновления

1. Одновременно измените версию в:
   - `desktopApp/build.gradle.kts` (`packageVersion`);
   - `desktopApp/src/main/kotlin/holypresenter/org/app/AppVersion.kt`.
2. Выполните предрелизную проверку из `TESTING.md`.
3. На Windows соберите MSI:

   ```powershell
   .\gradlew.bat :desktopApp:packageMsi
   ```

4. В GitHub создайте обычный (не draft и не prerelease) Release с тегом вида
   `v1.0.9` и приложите собранный `.msi` из
   `desktopApp\build\compose\binaries\main\msi`.
5. Убедитесь, что версия тега строго выше версии, установленной у пользователя.

Имя MSI может различаться, но в Release должен быть ровно один основной
установщик HolyPresenter. GitHub автоматически добавляет к asset поле `digest`
с SHA-256; отдельный файл контрольной суммы не требуется.

`upgradeUuid` в `desktopApp/build.gradle.kts` является постоянным идентификатором
линейки MSI. Его нельзя менять в будущих версиях, иначе Windows перестанет
считать новый MSI обновлением существующей установки.

Версия 1.0.8 — переходная: её нужно один раз установить обычным MSI. Все
следующие опубликованные версии можно устанавливать из самой программы.
