# Обновления HolyPresenter

Начиная с версии 1.0.9 пользователь может обновить установленную программу из
встроенного модуля **«Обновления»**. Удалять старую версию и повторно настраивать
HolyPresenter не нужно.

## Как это работает

1. HolyPresenter получает файл `holypresenter-update.json` непосредственно из
   последнего Release репозитория `maxx52/HolyPresenter`. Ограниченный GitHub
   REST API и персональный токен для этого не используются.
2. Результат проверки хранится локально шесть часов, поэтому повторное открытие
   модуля не создаёт лишних сетевых запросов. Кнопка ручной проверки обходит кэш.
3. Манифест содержит адрес MSI, размер и SHA-256. Без корректной контрольной
   суммы установка блокируется.
4. MSI скачивается в `%LOCALAPPDATA%\HolyPresenter\updates`, проверяется по
   размеру и SHA-256.
5. После подтверждения HolyPresenter корректно закрывает сервисы, запускает
   скрытый помощник обновления и освобождает файлы программы.
6. Windows показывает стандартный запрос UAC, устанавливает MSI поверх текущей
   версии и снова открывает HolyPresenter.

Настройки, планы, резервные копии, песни и установленные пользователем модули
находятся в `%LOCALAPPDATA%\HolyPresenter`, поэтому MSI их не удаляет.

## Публикация обновления

1. Одновременно измените версию в:
   - `desktopApp/build.gradle.kts` (`packageVersion`);
   - `desktopApp/src/main/kotlin/holypresenter/org/app/AppVersion.kt`.
2. Выполните предрелизную проверку из `TESTING.md`.
3. На Windows соберите MSI и манифест одной командой:

   ```powershell
   .\gradlew.bat :desktopApp:prepareUpdateRelease
   ```

4. В GitHub создайте обычный (не draft и не prerelease) Release с тегом вида
   `v1.0.9` и приложите два созданных файла:
   - `.msi` из `desktopApp\build\compose\binaries\main\msi`;
   - `desktopApp\build\update\holypresenter-update.json`.
5. Убедитесь, что версия тега строго выше версии, установленной у пользователя.

Gradle автоматически вписывает в манифест точное имя MSI, размер, ссылку и
SHA-256. Редактировать созданный JSON вручную не нужно.

`upgradeUuid` в `desktopApp/build.gradle.kts` является постоянным идентификатором
линейки MSI. Его нельзя менять в будущих версиях, иначе Windows перестанет
считать новый MSI обновлением существующей установки.

Версия 1.0.9 — переходная для нового манифеста: её нужно один раз установить
обычным MSI или получить через прежнюю проверку после сброса лимита GitHub. Все
следующие опубликованные версии можно устанавливать из самой программы без
ограниченного GitHub API.
