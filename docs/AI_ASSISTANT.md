# ИИ-помощник HolyPresenter

Встроенный модуль создаёт текст, изображения и короткие видео, показывает
предварительную стоимость и не выполняет запрос, если он превысит месячный
лимит пользователя.

## Экономные настройки по умолчанию

- текст: `gpt-5.6-luna`, не более 1200 выходных токенов;
- изображения: `gpt-image-2`, 1536×1024, среднее качество;
- видео: `sora-2`, 1280×720, 4 секунды;
- месячный лимит: 10 USD.

Перед каждым запросом HolyPresenter показывает оценку и требует подтверждение.
Фактическая стоимость успешного запроса записывается в
`settings/ai-usage.json`. Пользователь может увеличить лимит и выбрать более
мощную текстовую модель в расширенных настройках.

Лимит является локальной защитой HolyPresenter на конкретном компьютере. Для
жёсткого ограничения всего аккаунта дополнительно настройте бюджет проекта в
панели OpenAI.

## API-ключ

Каждый пользователь добавляет собственный ключ OpenAI. На Windows ключ
шифруется DPAPI для текущей учётной записи и хранится в
`cloud/openai-api-key.dpapi`. Каталог `cloud` исключён из резервных копий, поэтому
ключ не переносится на другой компьютер. Также поддерживается переменная среды
`OPENAI_API_KEY`.

Ключ нельзя добавлять в исходный код, JAR, MSI или журнал приложения.

## Расширение провайдерами

`AiProvider` и `AiProviderRegistry` находятся в `platform-api`. Внешний модуль
может реализовать собственный провайдер и зарегистрировать его при включении:

```kotlin
override fun onEnable(context: ModuleContext) {
    context.services
        .get(AiProviderRegistry::class)
        ?.register(MyAiProvider())
}
```

Провайдер обязан заранее оценивать стоимость, выполнять тяжёлую работу вне UI
потока и возвращать фактически списанную либо наиболее точную известную
стоимость.

## Ограничение видео

OpenAI объявила Videos API и Sora 2 устаревшими с отключением 24 сентября 2026
года. Поэтому видеогенерация отделена интерфейсом `AiProvider`: новый провайдер
можно подключить без изменения интерфейса ИИ-помощника и планировщика.
