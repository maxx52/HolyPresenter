# Резервные копии HolyPresenter на Яндекс Диске

HolyPresenter использует только изолированную папку приложения на Диске.
Приложению не требуется доступ к остальным пользовательским файлам.

## Регистрация OAuth-приложения

1. Откройте <https://oauth.yandex.ru/client/new> под аккаунтом разработчика.
2. Укажите имя `HolyPresenter` и значок программы.
3. Добавьте redirect URI:
   `https://oauth.yandex.com/verification_code`.
4. Разрешите только доступ к папке приложения:
   `cloud_api:disk.app_folder`.
5. Создайте приложение и скопируйте его Client ID.

Client ID не является секретом и может поставляться вместе с Desktop-приложением.
Client secret в HolyPresenter добавлять нельзя.

## Настройка сборки

Официальный Client ID уже встроен в HolyPresenter. Для тестовой или собственной
OAuth-конфигурации его можно временно переопределить одним из способов:

```powershell
$env:HOLYPRESENTER_YANDEX_CLIENT_ID = "полученный-client-id"
.\gradlew.bat :desktopApp:run
```

или вставить Client ID в поле на экране «Резервные копии». Значение сохранится
в `%LOCALAPPDATA%\HolyPresenter\cloud\yandex.json`.

OAuth-токены сохраняются отдельно в `yandex-token.dpapi` и шифруются Windows
DPAPI для текущего пользователя. Токены, логи, кэш и JAR-файлы модулей никогда
не включаются в `.holybackup`.

## Восстановление

После выбора копии HolyPresenter проверяет все файлы по SHA-256 и помещает
проверенный архив в очередь восстановления. Закройте и заново откройте
программу. Данные будут применены до загрузки настроек и модулей.

Видео не входят в копию по умолчанию. Их можно включить вручную перед созданием
архива.
